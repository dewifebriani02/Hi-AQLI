# Panduan Pengembangan Lokal (macOS)

Dokumen ini berisi tips dan instruksi khusus untuk pengembangan Hi AQLI menggunakan perangkat Mac.

## Menghentikan Server Pengembangan
Saat menjalankan server dengan `npm run dev`, Anda dapat menghentikannya kapan saja melalui terminal dengan menekan:

**`Control + C`** (Gunakan tombol **Control**, bukan Command).

## Menjalankan Server
Gunakan perintah berikut di terminal:
```bash
npm run dev
```
Aplikasi akan berjalan di [http://localhost:9002](http://localhost:9002).

## Perintah Penting Lainnya
- `Command + Option + I`: Membuka Developer Tools di Google Chrome.
- `Command + R`: Refresh halaman browser.
