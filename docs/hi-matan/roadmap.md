# Hi Matan: Development Roadmap

Rencana eksekusi pengembangan modul Hi Matan dibagi menjadi 3 fase utama untuk memastikan kualitas dan fungsionalitas yang teruji.

## Fase 1: Fondasi & Basis Data (Mulai)
- [ ] Migrasi database: Pembuatan tabel `matans`, `chapters`, `items`, dan `progress`.
- [ ] Penyusunan struktur folder `src/app/matan`.
- [ ] Integrasi data fetcher untuk mengambil materi dari database.

## Fase 2: UI/UX & Gamifikasi
- [ ] Implementasi "World Map" Dashboard.
- [ ] Pembuatan "Syarah Reader" (Immersive Reading Experience).
- [ ] Integrasi efek visual (Confetti, Glow) dan Feedback Audio.
- [ ] Sistem ranking "Nahwu XP".

## Fase 3: Integrasi & Polishing
- [ ] Sinkronisasi dengan modul Hi I'rab.
- [ ] Pembuatan kuis analitis ("Why Challenges").
- [ ] Optimasi performa dan animasi pada perangkat mobile.
